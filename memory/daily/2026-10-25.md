### The gate caught this session's own writing

The first full `validate_docs` run **failed with 7 blocking findings** — all in
docs written minutes earlier:

- **R2** (4×): the literal `98903` in the corrections table, the ADR, and the
  evaluation note. Real design flaw: the rule forbade naming a foreign host even
  where naming it *is* the correction. Fixed with an explicit, reviewable
  `FOREIGN_ALLOWLIST` of file paths (no wildcards) in the validator, plus a test
  proving an unlisted file still fails.
- **R5** (3×): credential-shaped fixtures in `tests/test_validate_docs.py`. Fixed
  with the standard inline escape (`pragma: allowlist secret`) applied per line,
  plus a test proving the marker does not cover the following line.

Test count rose 25 → 29, covering both escape hatches. This is the intended
behavior: the gate blocked the build until the *rules* were right, instead of the
rules being quietly relaxed or the evidence deleted.
